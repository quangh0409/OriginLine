# 1) SINH CAP KHOA - bang chinh cong cu cua du an, khong them phu thuoc nao
# =====================================================================================
#   cd backend
#   ./mvnw -q compile          # Windows: .\mvnw.cmd -q compile
#   java -cp target/classes vn.giapha.notification.infrastructure.webpush.VapidKeyGenerator
#
#   Cong cu in ra dung hai dong duoi day (P-256, base64url khong dem):
#     - khoa cong khai: 65 byte diem khong nen -> 87 ky tu, luon bat dau bang chu 'B'
#     - khoa rieng:     32 byte vo huong d     -> 43 ky tu

# =====================================================================================
# 2) NAP VAO TIEN TRINH BACKEND
# =====================================================================================
#   PowerShell (chi hieu luc trong cua so hien tai):
#     $env:GIAPHA_WEBPUSH_PUBLIC_KEY  = "<dan khoa cong khai>"
#     $env:GIAPHA_WEBPUSH_PRIVATE_KEY = "<dan khoa rieng>"
#     cd backend; .\mvnw.cmd spring-boot:run
#
#   bash:
#     export GIAPHA_WEBPUSH_PUBLIC_KEY="<dan khoa cong khai>"
#     export GIAPHA_WEBPUSH_PRIVATE_KEY="<dan khoa rieng>"
#     cd backend && ./mvnw spring-boot:run
#
#   Khoa chi duoc doc MOT LAN luc khoi dong (va tu kiem "hai khoa cung mot cap" ngay
#   tai do). Dat bien cho mot tien trinh dang chay khong co tac dung - phai khoi dong lai.
#
# =====================================================================================

# =====================================================================================

#   Chua cau hinh thi hai endpoint tren tra ready=false va 422 WEBPUSH_NOT_CONFIGURED.
