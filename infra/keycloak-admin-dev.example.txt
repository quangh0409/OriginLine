# =====================================================================================
# 1) VI SAO LA MOT CLIENT RIENG, KHONG PHAI `giapha-backend`
# =====================================================================================
#   `giapha-backend` la AUDIENCE cua moi token nguoi dung. Gan them quyen quan tri realm
#   vao dung client ay la gop hai muc rui ro hoan toan khac nhau vao mot bi mat. Vi vay
#   co client thu ba: `giapha-provisioner`, chi dung cho client_credentials, khong co
#   browser flow, khong co direct access grant.
#
# =====================================================================================
# 2) QUYEN TOI THIEU — DUNG MOT VAI CLIENT
# =====================================================================================
#   realm-management -> manage-users
#
#   KHONG PHAI `realm-admin`. Vai ay gop ca manage-realm, manage-clients,
#   manage-identity-providers va impersonation: mot bi mat ro ra se thanh quyen quan tri
#   toan realm — doi duoc luong xac thuc, tat duoc kiem mat khau, mao danh duoc bat ky ai.
#
#   Cung KHONG can `view-users` rieng: trong Keycloak `canView()` da dung khi nguoi goi
#   co quyen quan ly, nen `manage-users` tu phu ca tim kiem lan doc credential.
#
#   Hep hon `manage-users` thi Keycloak ban thuong khong co. Huong siet tiep theo la
#   fine-grained admin permissions cua Keycloak — ghi ra day de lan sau khong phai tim lai.
#
# =====================================================================================
# 3) TAO CLIENT TREN MOT REALM DANG CHAY
# =====================================================================================
#   Neu realm `giapha` da duoc nhap tu truoc thi `--import-realm` KHONG nhap lai, nen
#   client moi trong realm-giapha.json se khong tu xuat hien. Tao bang admin CLI:
#
#     docker exec giapha-keycloak /opt/keycloak/bin/kcadm.sh config credentials \
#       --server http://localhost:8081 --realm master --user admin --password admin
#     docker exec giapha-keycloak /opt/keycloak/bin/kcadm.sh create clients -r giapha \
#       -s clientId=giapha-provisioner -s enabled=true -s publicClient=false \
#       -s standardFlowEnabled=false -s directAccessGrantsEnabled=false \
#       -s serviceAccountsEnabled=true -s fullScopeAllowed=false \
#       -s secret='<bi mat cua ban>'
#     docker exec giapha-keycloak /opt/keycloak/bin/kcadm.sh add-roles -r giapha \
#       --uusername service-account-giapha-provisioner \
#       --cclientid realm-management --rolename manage-users
#
#   Kiem tra vai da gan dung MOT vai:
#     kcadm.sh get-roles -r giapha --uusername service-account-giapha-provisioner \
#       --cclientid realm-management
#
# =====================================================================================

#   bash:
